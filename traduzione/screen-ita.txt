screen -S nome_sessione	Crea una nuova sessione con un nome personalizzato

screen -ls	Mostra tutte le sessioni attive

screen -r nome_sessione	Ricollegati a una sessione esistente

CTRL + A, poi D	Detach (esci lasciando il processo in esecuzione)

CTRL + A, poi K	Kill (termina la sessione corrente)

CTRL + A, poi C	Crea una nuova finestra (tab) nella stessa sessione

CTRL + A, poi N	Passa alla finestra successiva

CTRL + A, poi P	Passa alla finestra precedente

exit	Chiude la sessione (se dentro screen)











Come eseguire lo script:
Dalla cartella c:\Users\utente\Desktop\ragnarokserver\robroswer\traduzione:

Per avviare la traduzione di tutta la cartella NPC:

powershell
.\venv\Scripts\python tradricorsivocodifica.py
(Su Linux / screen: python3 ./tradricorsivocodifica.py)
Lo script usa un intervallo predefinito di 1.5 secondi tra le richieste,
salva la cache e riprova automaticamente con backoff quando Google risponde
con rate limit (HTTP 429). Per essere ancora più prudenti:

powershell
.\venv\Scripts\python tradricorsivocodifica.py --delay 3

Per testare un singolo file:

powershell
.\venv\Scripts\python tradricorsivocodifica.py npc/cities/alberta.txt
Per forzare la ritraduzione e sovrascrivere i file esistenti:

powershell
.\venv\Scripts\python tradricorsivocodifica.py --force
Una volta terminato, per applicare i file tradotti (rimuovere originali e rinominare):

powershell
.\venv\Scripts\python riorganization.py
(È stato corretto anche il percorso predefinito in 

riorganization.py
