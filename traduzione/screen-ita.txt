Come eseguire lo script:
Dalla cartella c:\Users\utente\Desktop\ragnarokserver\robroswer\traduzione:

Il traduttore usa solo Ollama tramite API locale OpenAI-compatible:

http://127.0.0.1:8080/v1

Modello predefinito:

google/gemma-4-e4b

La cache viene salvata in translation_cache.json. Non vengono usati Google
Translate, deep-translator, cookie o servizi esterni.

## Modalità 1: rebuild offline dalla cache

powershell
.\venv\Scripts\python tradricorsivocodifica.py --rebuild-from-cache

Questa modalità:

- non contatta Ollama e funziona senza Internet;
- ricrea e sovrascrive tutti i file -ita.txt;
- copia direttamente le frasi già presenti nella cache;
- lascia in inglese le frasi non ancora presenti nella cache;
- salva i file incompleti in translation_pending.json.

## Modalità 2: ricostruzione e completamento con Ollama

powershell
.\venv\Scripts\python tradricorsivocodifica.py

Questa è la modalità da usare per completare il lavoro:

- ricrea e sovrascrive tutti i file -ita.txt;
- usa direttamente la cache per le frasi già tradotte;
- invia a Ollama solo le frasi assenti dalla cache;
- aggiunge le nuove traduzioni alla cache;
- se la cache non esiste, la crea da zero;
- se una richiesta fallisce, salva il file in translation_pending.json;
- può essere interrotta con CTRL+C e ripresa senza perdere la cache.

Quindi il flusso consigliato è:

1. usa --rebuild-from-cache per ricostruire gli output senza Ollama;
2. avvia il comando normale quando Ollama è attivo;
3. il comando normale ricrea gli output e completa solo le frasi mancanti.

Configurazione del server locale:

- avvia Ollama o il proxy OpenAI-compatible sulla porta 8080;
- assicurati che il modello esposto si chiami google/gemma-4-e4b;
- se il nome è diverso, imposta OLLAMA_MODEL prima dell'avvio.

Esempio PowerShell:

$env:OLLAMA_MODEL = "google/gemma-4-e4b"
.\venv\Scripts\python tradricorsivocodifica.py

Per testare un singolo file:

powershell
.\venv\Scripts\python tradricorsivocodifica.py npc/cities/alberta.txt
